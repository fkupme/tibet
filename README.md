# РумТибет — лендинг турфирмы

Адаптивный лендинг турфирмы, которая возит в походы по Тибету и Гималаям. Vue 3 (`<script setup>`) + Vite.

**[Демо →](https://tibet-pi.vercel.app/)**

![РумТибет](docs/preview.jpg)

## Что внутри

- **Три брейкпоинта** — мобильный (< 640), планшет (640–1024), десктоп. Раскладка решается в CSS, а JS подключается только там, где меняется сама разметка (слайдер на мобильном, сетка на десктопе). Для этого есть composable `useMediaQuery` на `matchMedia`
- **Популярные направления** — Swiper с виртуальными слайдами, бесконечной прокруткой, навигацией с клавиатуры и брейкпоинтами. По клику или Enter открывается карточка направления: модалка через `Teleport`, закрывается по Esc и клику по фону, скролл страницы на это время блокируется
- **Поиск тура** — на мобильном раскрывается в панель, на десктопе это строка полей. Список локаций строится из данных о направлениях, так что они не разъедутся
- **Подписка на рассылку** — своя валидация email и согласия: поле перепроверяется на лету после первой ошибки, во время отправки кнопка показывает состояние загрузки
- **Контент отделён от вёрстки** — направления, блог, галерея, меню и футер лежат в `src/data`, компоненты только отображают данные
- **Картинки** подключаются через `import.meta.glob` по соглашению об именах `name.png` / `name-desktop.png`

## Стек

Vue 3.5 (Composition API, `<script setup>`, `defineModel`), Vite, Swiper 11, SCSS (`@use`, токены подключаются автоматически), ESLint (flat config) + Prettier

## Запуск

```bash
npm install
npm run dev       # dev-сервер Vite
npm run build     # продакшен-сборка в dist/
npm run preview   # локальный просмотр сборки
npm run lint      # ESLint
```

## Структура

```
src/
├── components/
│   ├── layout/        # TheHeader, NavMenu, TheFooter
│   ├── sections/      # секции страницы
│   ├── cards/         # карточки и модалка направления
│   ├── search/        # форма поиска тура
│   ├── forms/         # подписка на рассылку
│   ├── footer/        # блоки футера
│   └── ui/            # BaseButton, SectionTitle, CloseButton
├── composables/       # useMediaQuery, useEscapeKey, useScrollLock
├── data/              # контент страницы
├── styles/            # токены (переменные, миксины), глобальные стили, reset
├── utils/images.js    # подключение картинок по имени
└── assets/            # шрифты, картинки, иконки
```

## Деплой

Vercel собирает проект из исходников (`vercel.json`, пресет Vite), папка `dist` в репозиторий не коммитится.
